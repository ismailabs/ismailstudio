## Progress file template
For each phase record: **timestamp, goal, files edited, skill(s) reviewed/applied, tool/command actually run, visual evidence paths, failures and repair, done gates, unresolved blockers, next step**. Keep summary short and source-controlled; don't expose secrets or customer form submissions.

## Blocking vs nonblocking
Nonblocking: polish bug, optional analytics custom events, vendor cost estimate, optional PNG refinements; resolve while continuing. Blocking: no deployment permission, inability to preserve DNS/email, no eligible form-provider access, actual form delivery failure, critical accessibility/security flaw, unsupported business claim. Escalate only genuine unresolvable blocking dependency after independent diagnostics; don't ask repetitive approval on routine choices.

## Operating discipline
No background-work promises; execute within actual Codex run. If interrupted or compacted, resume from progress file and repository state. Preserve a reproducible test log. Stop when verified definition of done met rather than endless aesthetic churn.
