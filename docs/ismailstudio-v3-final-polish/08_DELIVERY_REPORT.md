# Final delivery and issue-report contract

The agent must deliver a concise, accurate owner-readable completion report on the active Codex task, with links/paths to actual evidence. Keep secrets, raw mailbox data and customer details private. Do not assert future continuation after Codex is closed.

## Required report fields

- **Status:** RELEASED / PREVIEW ONLY (BLOCKED) / LOCAL ONLY (BLOCKED). No “released” unless public site verified.
- **Target:** `https://www.ismailstudio.my/`, and actual working preview URL if used.
- **Source:** branch, full commit SHA, observed starting SHA and any uncommitted owner-owned changes **explicitly preserved and not staged**.
- **Hero approvals:** approved desktop original SHA-256 and mobile A background SHA-256; optimized output paths/hashes/sizes, visual review screenshots and no embedded headline in bitmap.
- **Changes:** file-level concise list grouped by Hero, Nav/Motion, About/Offers/Case Studies/FAQ, SEO, Form, Quality/Docs.
- **Facts verified:** H1, From prices/pages/revisions, one-time SEO, four Concept Projects/live links, location, short title and honest policy/timeline treatment.
- **Unresolved decisions:** working vs calendar days gate and any owner-selected commercialization terms still open. Never hide a release block.
- **Tests:** actual commands, numbers/pass/fail/skips, source/URL/time, mobile/desktop screenshot links, axe/keyboard/no-JS/reduced-motion, perf raw results and comparison bounds.
- **Form:** isolated UI test results; if real authorized send, exact provider acceptance and independent owner-verified inbox receipt without personal content. Otherwise unresolved gate.
- **Cloudflare:** exact worker ID/name, version ID, deployment ID, UTC local time, traffic %, protected DNS/apex/mail/unrelated resources before/after, rollback known-good version/action.
- **GitHub:** branch link, commit link, CI run(s), changed assets and no force push; accurately state whether main was updated or only branch published.
- **Known limitations:** physical-device testing, Search Console data, site field CWV, missing permissions or required owner action.
- **Next action:** if release blocked, exactly what the owner must do and why; do not ask for routine changes.
