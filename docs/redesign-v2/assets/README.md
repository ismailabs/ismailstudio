# Asset usage, rights and authority

`approved-mockups/frames/`: user-approved static layouts, a reference for Codex to reimplement in responsive HTML/CSS/JS. Do not publish these frame images as site sections. 17 individual PNGs and two overview JPG boards. Visual text may be wrong; docs and current repo facts override.

`approved-concepts/`: three selected, AI-generated **mood explorations**. Secondary references only. Their UI project images are potentially reimagined; never treat them as authentic project captures.

`project-preview-crops/`: four genuine project UI captures **cropped from user-supplied screenshots** during mockup review. Review-only. For production, use `public/assets/projects/` and verified live project screens directly from current repo, without generative replacement.

`directional-only/glass-sculpture.webp`: generated transparent-ish abstract design cue, **not inherently a unique studio trademark**. Replace with coherent studio-specific brand interaction or document a strong reason why a remade version is distinctive. Respect LCP/performance and reduced-motion.

`prototype/prototype.html`: exploratory static sketch, **not a production starter** and not an accessibility- or form-verified app. Its form UI does not send enquiries.

No proprietary Awwwards imagery or remote company code is included. Any new imagery/fonts/animation libraries sourced by Codex require licensing/provenance review.
