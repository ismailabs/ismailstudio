## Evidence classes

- User decisions and direct source screenshots: confirmed inputs.
- Static mockup images: approved **visual** direction, not runnable website or text source.
- GitHub snapshot: observed repository state at the cited SHA, may be outdated.
- V1 release notes: *historical* claims of tests and provider delivery, not fresh V2 proof.
- External gallery descriptions: inspiration only, require independent review before detailed assertion.
- Implementation screenshots and test results: to be generated by Codex; none in this package are evidence of a V2 production implementation.
