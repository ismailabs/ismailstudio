# Brand mark, wordmark and favicon

The user liked the new **white minimalist monogram / Ismail Studio wordmark** displayed in the four approved mockups. Preserve its visual character but produce a genuine consistent identity system rather than cropping the PNG and calling it a logo.

## Approved character

- Abstract but instantly readable at small sizes; approachable geometric forms, **rounded** terminals and strong optical balance.
- Strong white-on-dark hero lockup; high-contrast dark-on-light variant.
- Avoid the V2 angular `[IS]` 3D block symbol and avoid overly complex chrome mark that is unreadable at favicon size.
- The wordmark should comfortably read 'ismail studio', with clear distinction between stacked/inline lockups where needed.

## Required production assets (for later Codex handoff)

1. Fully original **editable vector** symbol with semantic proportions and clean strokes/fills.
2. Wordmark horizontal and stacked variants, full-color/accent subtle, solid-black, solid-white.
3. SVG favicon (tiny tested), PNG 16, 32, 48, 180/192 and 512 variants where appropriate; browser pinned-tab support if relevant.
4. Accessibility: meaning not lost at 16px, text alternative for full brand; decorative icon hidden when adjacent accessible wordmark is present.
5. Screenshot comparing favicon/mark legibility at 16, 32, 48, 64, and 128px on light and dark backgrounds.
6. No tracing/copying a third party trademark. No unlicensed fonts/brand assets.

`assets/approved-mockups/logo-study-crop.png` shows **what the user visually approved**. It is a pixel crop and contains no editable vector source. If a pixel-exact logo is critical, a manual vector recreation and owner sign-off may be necessary. The later Codex stage should implement a faithful, original approximation within the approved visual contract and document deviations.
