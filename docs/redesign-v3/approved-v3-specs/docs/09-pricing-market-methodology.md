# Malaysian competitor / market-price comparison — evidence rules

The user wants public market price context **below the three offers** and intends to show competitive value. This does **not** authorize an untrue claim that Ismail Studio is cheaper than every competitor.

## Evidence method for final Codex stage

1. On execution day, sample 3–6 relevant Malaysian providers whose actual **public price pages** disclose website category, currency, minimum pages, inclusions and recurring costs. Record exact URL, access date, listed price and caveats.
2. Separate one-page sites, ~5-page small business sites and ~12-page broader sites. Do not compare a one-page template to a 12-page custom design as interchangeable services.
3. Label the display **'Examples of published Malaysian website prices'**, or source-constrained published ranges, **not** a statistically representative national mean or an audited competitor ranking.
4. Show Ismail Studio starts at RM599 / RM1,299 / RM2,999 and is scoped differently; no generalized percentage 'savings' unless truly matched scope and computed correctly.
5. Include source links and 'Checked on YYYY-MM-DD' plus methodology. Re-check on release day; omit stale values if provider pricing changes.
6. Separate one-time build cost from annual hosting, domains, maintenance, backend, content, add-ons and taxes.
7. If reliable public comparable data is insufficient, **do not invent ranges**. Publish a concise value explanation or defer the comparison module rather than fabricate a graph.

## Design rules

Light muted market-context strip, small enough not to drown the offers, big enough to be legible. No aggressive competitive marketing, false scarcity, fabricated testimonials or 'lowest price in Malaysia' badge. A few well-labelled bars or columns are enough. Each number must cite a verified source.

The approved generated pricing mockup includes invented market range numbers and a 'Most Popular' ribbon. These are **not** confirmed claims and must be discarded.
