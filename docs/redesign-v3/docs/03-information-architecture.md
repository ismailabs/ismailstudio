# Content hierarchy and route plan

Homepage is the primary experience, with four existing dedicated concept-study pages preserved: `/work/kilatmoto/`, `/work/makansedap/`, `/work/kopikita/`, `/work/malaysia/`. Avoid unnecessary new routes or app framework rewrites.

**Narrative order:** animated floating navigation → cinematic H1 hero → light selected work → light concise problem/solution argument → light three offers → neutral sourced market comparison → light icon-led approach → calm About (one optional contrasting panel) → light concise FAQ → prominent guided contact → short footer.

## Scope per section

- **Hero:** H1, one-sentence offering/region, one main 'Get a Website Quote' button and one work exploration link. Don't crowd with '100% independent', badges, counts or unsupported credentials.
- **Work:** all four authentic live concepts, thumbnail as dominant item, **Concept Project** visible, concise category, case-study preview and external live link. Work gallery may use 2-column desktop/stacked mobile; prioritize large images.
- **Business problems:** four themes — explain clearly, establish credibility, improve technical discoverability, facilitate customer action; use one large statement + short supporting examples. Don't invent conversion improvement.
- **Offers:** Starter, Business, Premium are clear and comparable. Cards contain actual limits and tiered SEO; additional exclusions accessible through clear note/disclosure. No pricing-change animations that hide fees.
- **Market context:** optional if sufficiently grounded; for categories with different scope, do not imply direct comparison.
- **Process:** a sequence of 5 big **Lucide** glyphs (`messages-square`, `clipboard-list`, `code-2`, `scan-eye`, `rocket` or validated suitable equivalents), short verb labels + a short explanatory clause (not icon-only ambiguity), no old numeric path.
- **About:** ambitious developer, practical solutions, craftsmanship, honesty, direct communication, Melaka; no age, fabricated biography/photo/team.
- **FAQ:** 5–7 questions answering real purchase uncertainties based on verified terms; answer in 1–3 brief sentences, not 250-word articles.
- **Contact:** 3 steps (your details → project needs → review/send), real Name/Business/Email/Package/Timeline/Message, verified sender flow, transparent privacy, email fallback.

Section IDs/navigation should be stable (`#work`, `#services`, `#process`, `#about`, `#contact`) with section offset for floating nav. Preserve existing study permalink functionality, FAQ direct access and SEO canonical behavior. No JS-only access for core content.
