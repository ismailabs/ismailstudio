# New logo, favicon, art and typography — production brief

## Logo system

Reinvent the previous angular `[IS]` portal. Inspired by `approved-v3-specs/assets/approved-mockups/logo-study-crop.png`, design a **new original readable symbol**, not a trace of an existing brand, plus a carefully proportioned wordmark 'ismail studio'. Build SVG as native vector artwork: icon-only, stacked, inline, black-on-light, white-on-dark and limited approved accent variant. Use well-specified optical shape dimensions and a coherent clear-space rule. Inspect at 16, 24, 32, 48, 64, 128px; publish favicon.svg, valid png favicon(s), touch icon and consistent OG image. No trademark-registration claim. Icon must not turn into an illegible microscopic doodle.

## Hero

Compose two layers: dramatic mountains/cloud horizon `approved-v3-specs/assets/approved-background-study/cinematic-art-right.webp` where technically suitable, plus carefully art-directed iridescent dimensional subject from approved images. Could optimize/recompose permissible generated artwork if licensing/visual quality fit; no requirement for expensive WebGL. Keep H1 in semantic HTML above gradient/scrim, not baked into image; maintain wide and mobile crops, decisive white type with restrained gradient for 'BIGGER' only. Original generic blob/chrome knot is insufficient if it obscures brand or message. The feature must feel like *one* designed statement.

## Light sections and imagery

Pure or warm-neutral white/light silver as dominant content surfaces. Use negative space and one substantial art/photo per important section rather than repeating gradients/borders. Never replace four authentic project screenshots. Real project screenshots retain their own original visual palettes (orange inside them is allowed).

## Typography and sizing (initial candidates; test actual rendered images)

Prefer one display face with strong bold cut plus one readable body family (or well-designed single variable family). Commercially compatible self-hosted fonts only, license documented. Body desktop generally 17–20px; mobile 16–18px; essential labels generally >=14px; H1 desktop approximately clamp(64px, 6–9vw, 136px), mobile clamp(42px, 10vw, 72px) but adjust to line breaks and screenshot. These are targets, not mandated CSS. Use generous line-height for body, modest tracking, logical heading order and no text-overlap. Ensure nav/logo comfortable at real screenshot zoom.

## Palette

Base near-black ~#070B14 / white ~#F7F9FC / neutral silver-blue, with sparse iridescent blue-violet-magenta accent. Final values must pass contrast on each text/background combination. **No orange in new UI; preserve orange within genuine project screenshots.** Rounded components about 12–20px with pill-shaped primary CTAs. Never force rounded browser screenshot content or break focus rings.

## Artifact requirements

Commit production SVG(s), favicon and OG, assets with provenance manifest/license assessment. Add screenshot comparison for identity on header, mobile menu, footer and favicon at several sizes. Iridescent cropped bitmap is not an editable 3D source or a guaranteed perfect animation object; create efficient CSS/composited subtle motion with static image fallback.
